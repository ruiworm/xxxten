把 Jan 里的模型迁移到 LM Studio

适用 Windows。Jan 和 LM Studio 用的是同一种模型文件（.gguf），所以不用重新下载，搬过去就能用。整个过程大约 5 分钟。

这份教程只讲一件事：把已经下好的模型从 Jan 搬到 LM Studio。不涉及下载新模型。

迁移前先认清一件事

两个软件的文件夹结构不一样，这是唯一需要理解的地方。

Jan 是这样（一层）：

Jan 的模型目录\
└── Qwen3-8B\
    └── model.gguf

LM Studio 要这样（两层）：

LM Studio 的模型目录\
└── qwen\              ← 第一层：随便起个名
    └── Qwen3.5-9B\      ← 第二层：模型名
        └── model.gguf

LM Studio 只认两层。少一层的话，模型不会出现在列表里，而且不报任何错误——界面一片安静，你会以为软件坏了。

所以搬的时候不能整个文件夹拖过去，必须多套一层。

第一步：找到 Jan 的模型在哪

Jan 的模型藏在系统目录里，路径比较深。

打开「此电脑」，在最上面的地址栏粘贴这个路径，回车：

%APPDATA%\Jan\data\llamacpp\models

如果提示找不到，说明你的 Jan 是老版本，换成：

C:\Users\%USERNAME%\jan\models

进去之后，你会看到一个个文件夹，每个文件夹就是一个模型。

如果两个路径都不对，说明你改过 Jan 的存放位置。打开 Jan → 设置（Settings）→ 通用（General），里面有一行 Jan Data Folder，旁边有个按钮能直接打开真实位置。

第二步：判断哪些能搬

点开任意一个模型文件夹，你会看到类似这些文件。不是每个都要搬：

你看到的文件 是什么 搬不搬
model.gguf 模型本体 要搬
mmproj.gguf 视觉模块（只有能看图的模型才有） 要搬，和主模型放一起
model.gguf.tmp 没下载完的半成品 不能搬
model.gguf.url 一个网址记录 不用
model.yml Jan 自己的配置文件 不用

重点看 .tmp。 它看着有体积、名字也对，但只要结尾是 .tmp，就说明当初下载中断了。这种文件改名搬过去，LM Studio 能认出来，但一加载就报错。

判断方法：只要文件夹里有 model.gguf（结尾就是 .gguf），这个模型就是完整的，可以搬。

第三步：打开 LM Studio 的模型目录

不同版本的 LM Studio，这个入口的位置不一样，有的叫 My Models，有的翻译成「我的模型」，有的只剩一个文件夹图标、没有文字。所以别去找菜单，直接用路径。

打开「此电脑」，在地址栏粘贴：

%USERPROFILE%\.lmstudio\models

回车。这个文件夹就是 LM Studio 放模型的地方。

打不开怎么办：

  • 提示找不到 → 你的 LM Studio 是老版本，换成 %USERPROFILE%\.cache\lm-studio\models
  • 两个都不对 → 你改过模型存放位置。打开 LM Studio → 设置（Settings）→ 找 Model Directory（模型目录），那里显示的就是真实路径

第四步：建两层文件夹，把模型粘贴进去

现在把 Jan 的模型搬过来。

以 Qwen3.5-9B 这个模型为例：

  1. 在 LM Studio 的模型目录里，新建一个文件夹，名字随便起，比如 qwen
  2. 进入 qwen，再新建一个文件夹，用模型名，比如 Qwen3.5-9B
  3. 回到 Jan 的目录，进入那个模型文件夹，选中 model.gguf
  4. 复制（不是剪切），粘贴到刚建的 Qwen3.5-9B 文件夹里
  5. 如果那个模型还有 mmproj.gguf，也一起复制进同一个文件夹

做完之后应该长这样：

C:\Users\你的用户名\.lmstudio\models\
└── qwen\
    └── Qwen3.5-9B\
        └── model.gguf

几个细节：

  • 文件名不用改。 model.gguf 这个名字可以照用，LM Studio 会从文件内部读出模型信息。
  • 一层里只放一个模型。 两个 gguf 塞进同一个文件夹会显示混乱。
  • 用复制，不要用剪切。 先确认 LM Studio 里能正常加载，再回头删 Jan 的，避免中途出错两头空。
  • 要搬多个模型，就重复这套动作，每个模型在 qwen 下面各占一个文件夹。

第五步：重启 LM Studio，确认搬成功了

  1. 完全关掉 LM Studio（右下角托盘图标也要退出）
  2. 重新打开
  3. 在聊天界面顶部的模型选择下拉框里找刚搬进去的模型
  4. 选中它，点 Load（加载）

能加载起来、能正常对话，就说明迁移成功了。

如果列表里还是没有：

回到第四步检查文件夹结构，99% 的情况是只建了一层——把文件直接放在了 qwen 里面，而没有放在 qwen\模型名\ 里面。

第六步：确认没问题后，清理 Jan（可选）

LM Studio 里能用了，Jan 那边就可以删了，能腾出空间。

可以删： 第一步打开的那个 models 文件夹下面的各个模型文件夹。

不要删： 整个 Jan\data 目录。里面除了模型，还有你的聊天记录和助手设置，删了整个 Jan 就恢复出厂状态了。

常见问题

模型列表里看不到
文件夹少了一层。检查是不是 models\发布者\模型名\文件.gguf 这个结构。

能出现，但加载报错
搬的可能是 .tmp 未完成文件。回去看文件名结尾是不是真的 .gguf。

加载很慢，或者一个字一个字往外蹦
模型太大，显存装不下，一部分在内存里跑。这不是迁移的问题，换个体积小一点的模型就好。

Jan 里明明有，但复制不出来
可能 Jan 还在后台运行，占着文件。退出 Jan（含托盘图标）再复制。

找不到 Jan 的模型目录
用 Jan 设置里的 Jan Data Folder 按钮打开，那个最准，不受版本影响。

搬过去占用双份空间
复制本来就是两份。如果你想只占一份，确认 LM Studio 能正常加载后，把 Jan 那边的原始文件删掉即可。

一句话总结

找到 Jan 的 model.gguf → 在 LM Studio 的模型目录里建「发布者 / 模型名」两层文件夹 → 粘进去 → 重启 LM Studio。
